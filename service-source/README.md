# Profullstack service marks

This folder carries the published icons for the 80 properties listed on Profullstack.com. SVGs stay vector; PNG fallbacks are embedded in the generated OpenIcon SVG and rasterized at the set sizes.

When a property has not published its own logo yet, its Profullstack house mark is used until that property has one. The exact source URL for each entry is recorded in `cli-tools/src/icon-service-brands.ts` and in `openicon.json`.
